How this is made (tech stack)

Schedule
A GitHub Actions job runs every Monday at about 7:00 AM Philippine time and writes one poem. It can also be run by hand. The site owner can pause or switch off this automation at any time, without notice.
Cities
A fixed list of cities across the Philippines, picked arbitrarily for geographic variety. Each week uses the next city in the list. Being on the list isn’t a ranking or a preference, and leaving a city out means nothing either.
Weather data
Open-Meteo forecast API (free, no account), one request per poem.
AI model
gpt-oss-20b, an open-weight model by OpenAI (Apache 2.0), reached through the free Pollinations text API. It receives only the city name and weather numbers.
Safety checks
A strict system prompt, then code that rejects any poem naming people, brands, or other places, or containing numbers, links, politics, or dark themes. If the weather or the AI fails, nothing is published.
Storage
A JSON file in the project’s repository, no database, capped at the 5 most recent poems. The oldest is removed automatically.
Website
One static HTML page with built-in CSS and JavaScript, no frameworks, hosted on GitHub Pages. The scripts run on Node.js with no external packages.
